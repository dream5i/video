# ADR Template

状态：Draft
日期：YYYY-MM-DD

## 标题

一句话描述这次决策。

## 背景

说明：

- 当前问题是什么
- 为什么现在必须做决定
- 涉及哪些范围

## 决策

明确写：

- 我们决定做什么
- 不做什么
- 当前适用边界是什么

## 备选方案

至少列出 2 个备选：

1. 方案 A
2. 方案 B

每个方案简述：

- 优点
- 缺点
- 为什么没有采用

## 影响

说明决策带来的影响：

- 产品影响
- 架构影响
- 数据 / contract 影响
- 开发流程影响

## 实施与回滚

说明：

- 后续如何实施
- 哪些文档要同步
- 如果要回退，回退条件是什么

- `docs/...`
- `AGENTS.md`
